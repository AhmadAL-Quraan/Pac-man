## Overview

* This a simple pac-man game project made in python.
* The game will consist of multi levels.
* At the start of the game you will have 4 ghosts that will be at the corners and pacman at the middle.
* The point is to eat all the pacgums to go to the next level, and to try to achieve maximum score possible.
